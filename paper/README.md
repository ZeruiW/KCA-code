## Using it on Overleaf
1. Overleaf → **New Project → Upload Project** → choose `KCA_overleaf.zip`.
2. Menu → Settings: **Compiler = pdfLaTeX** (the default), **Main document = `main.tex`**.
   `aaai2027.sty` refuses XeLaTeX/LuaLaTeX, so do not switch the compiler.
3. Recompile. BibTeX runs automatically (`main.bib`, style `aaai2027.bst`).

Expected result (checked locally with pdfLaTeX + BibTeX, TeX Live / TinyTeX): 18 pages, no `??`, no undefined
references or citations, no overfull boxes. **The main text currently runs about one page over the 7-page limit
(it ends three lines into page 9). This is deliberate: the author kept the full content and the trimming is still to be
done by hand.** Figure 3 (deletion/insertion curves) is page-wide (`figure*`) so that each panel is a column wide.
The end of the main text is marked by `\label{maintext-end}` after the conclusion (`main.tex`).

## AAAI rules this source already follows (please keep them)
- No `hyperref`, `geometry`, `cuted`, `\clearpage`, negative `\vspace` near floats, or `\resizebox` on tables.
  Tables are shrunk with `\small` / `\tabcolsep`; table captions go **under** the table.
- Do not change the lines marked `% DO NOT CHANGE THIS` in `main.tex`.
- Citations are author-year (`natbib`, no options). Author-year citations do not fit inside table cells, so
  `\tablecitesoff` (in `preamble.tex`) silences `\cite` inside the generated table bodies; the methods are cited in the text.
- Sections are numbered (`\setcounter{secnumdepth}{2}`, allowed by the kit).
- Camera-ready (only if accepted): `\usepackage{aaai2027}` without `[submission]`, and a real author block.

## Where every number comes from — do not hand-edit `tables/`
Nothing in the tables or quoted in the text is typed by hand. Everything under `tables/` and every result figure
under `fig/` is generated by the companion code package (`KCA_code.zip`) from the per-clip result records:
- `tables/numbers.tex` — every number the text quotes, as a macro (`\NumPFTKcaCtxDel`, `\NumXMotShare`, …);
- `tables/defaults.tex` — a red **??** for any macro the text uses but no result defines yet;
- `tables/tab_*.tex` — table **bodies** only, pulled in with `\tabinput{...}`. The `tabular` wrappers and the
  captions live in `sec/*.tex`, so captions and layout can be edited freely in `sec/`.

Generators (in the code package): `code/src/kca/run/paper_tables.py` (tables and numbers),
`code/src/kca/run/paper_figures.py` (`fig/msr_teaser.pdf`, `msr_qual.pdf`, `msr_curves.pdf`, `dissociation.pdf`,
`sanity.pdf`), `code/src/kca/run/make_controlled_figures.py` (`fig/controlled_*.pdf`), `code/src/kca/run/scale_table.py`
(`tables/tab_scale.tex`). If a number has to change, re-run the generator and upload the regenerated files here;
an edit made directly in `tables/` is overwritten by the next regeneration.

The main text uses the **full-scale** run (official model width, 2048 points per frame, trained on an A100;
results in `code/results/msr_full/`). The laptop-scale run (`code/results/msr/`) appears in the appendix as a second
training scale. The appendix section "Data, models and code behind each result" maps every table and figure to its
data, models and per-clip records.
